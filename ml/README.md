# IA — Binôme 2 (Harilaza)

Création du modèle qui étudie les symptômes et recommande des médicaments selon le stock
disponible. Entraînement, évaluation, diagnostic, optimisation, sortie du modèle final.

- `notebooks/` → exploration et expérimentations (EDA)
- `src/` → code du modèle : `preprocessing.py`, `train.py`, `predict.py`
- `models/` → modèle final sérialisé (`model_final.pkl`)
