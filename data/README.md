# Données — Binôme 1 (Larissa, Fideline)

Tâches : collection des données, EDA, nettoyage, encodage des variables catégorielles,
division train/test, feature scaling, feature selection, création de nouvelles variables,
suppression des valeurs aberrantes.

- `raw/` → données brutes telles qu'elles ont été collectées
- `processed/` → données nettoyées et prêtes pour l'entraînement

⚠️ Les fichiers de données brutes ne sont pas versionnés sur git (voir `.gitignore`).
Indiquer leur origine et version dans un README ici si nécessaire.
